# Group55_CMPG223_Project
The Library Management System is a software solution designed to streamline the management of books, readers, members, loans, and events in a library. It allows for easy management of the library's book inventory, member registrations, and tracking of books that are loaned out. The system also provides functionality for organizing events related to books and generating reports on event participation. This system uses a relational database to store data, ensuring that all interactions are recorded and easily accessible.

The system includes features such as adding, updating and deleting of books and members, managing loan details including due dates, and generating detailed reports. One of the key functionalities is the ability to generate reports on the top 5 books based on their involvement in events or the number of attendees. This makes it easy to track which books are most popular in the library and which events are most engaging to readers.

Built with C# and Windows Forms, this application is connected to a SQL Server database, using ADO.NET for data management. The library system is easy to set up and deploy, requiring only basic configuration of the connection string and the creation of necessary database tables. Whether you are managing a small library or handling large-scale operations, this system provides a robust solution for efficient library management.
